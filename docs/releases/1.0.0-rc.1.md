# `@worldhacker/kasane@1.0.0-rc.1`

Status: published and accepted after exact-commit CI, final audit,
release-manager approval, and registry artifact verification.

## Purpose

This is the exact candidate for `1.0.0`. The beta API and option freeze remains
active. No feature, optional optimization, or planned API experiment is part of
this release. Any code or generated-output change after publication requires a
new RC.

## Install

```bash
npm install @worldhacker/kasane@rc
```

Kasane is ESM-only, supports Node.js 22 and 24, and has zero runtime
dependencies. CommonJS compatibility remains outside scope.

## Promotion contract

The stable package must be produced by the same protected workflow and differ
from this audited RC only in `package.json` version metadata. The
[signed checklist](./rc-checklist.md), [final audit](./rc-final-audit.md), and
[soak-equivalent record](./rc-soak-equivalent.md) own the immutable evidence.

## Known limitations

The feature set and limitations are unchanged from beta. See
[Limitations and non-goals](../guides/limitations.md). No migration is required
beyond selecting the `rc` tag; rollback is documented in
[migrations](../migrations.md#01-beta-to-10-release-candidate).
