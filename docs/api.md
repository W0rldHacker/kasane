# Public API reference

This reference covers the stable ESM surface of Kasane `1.0`. It is checked
against the declarations exported by `src/index.ts` and
`src/standard-schema.ts`; [the declaration report](../etc/kasane.api.md) catches
signature drift. Semantic guarantees link to the user guides and accepted
[architecture decisions](./adr/README.md).

The only supported import specifiers are:

```ts
import { kasane } from '@worldhacker/kasane';
import type { StandardSchemaV1 } from '@worldhacker/kasane/standard-schema';
```

Generated files under `dist`, source-tree modules, and any other subpath are
internal even when a declaration file happens to exist after a local build.

## Pipeline entry point

### `kasane(options)`

```ts
function kasane<T = ConfigNode>(
  options: KasaneOptions<undefined>,
): Promise<ConfigSnapshot<T>>;

function kasane<Validation extends ValidationAdapter>(
  options: KasaneOptions<Validation> & { validate: Validation },
): Promise<ConfigSnapshot<InferValidationOutput<Validation>>>;
```

Loads enabled layers sequentially, normalizes and merges each result, validates
the completed value when requested, and returns a detached snapshot. Failure or
abort returns no partial snapshot. `T` without validation is a caller assertion;
the validator overload derives its result from runtime evidence.

`KasaneOptions` contains `layers`, `cwd`, `fingerprintKey`, `freeze`, `limits`,
`merge`, `onEvent`, `provenance`, `secrets`, `signal`, and `validate`.
`MergeRuleDeclarations` maps exact canonical paths to `MergeStrategy`.

`DEFAULT_MAX_SOURCE_BYTES` is `10_000_000`. `DEFAULT_KASANE_LIMITS` is a frozen
`ResolvedKasaneLimits` with `maxDepth: 64`, `maxNodes: 100_000`,
`maxStringLength: 1_000_000`, and `maxSourceBytes: 10_000_000`. Applications may
override these fields through `KasaneLimits`; raising them raises worst-case CPU
and memory use.

## Layer constructors

### `value(name, data, options?)`

Creates an in-memory layer. `ValueLayerOptions` exposes `enabled` and `secret`.
Input is never mutated and crosses normal normalization limits before merge.

### `file(name, filePath, options?)`

Creates a bounded UTF-8 file layer. `FileLayerOptions` exposes `enabled`,
`optional`, `parse`, and `secret`. `FileParser<Output>` may return an output or
promise. `optional: true` suppresses only missing-file `ENOENT`; parsing,
permissions, size, and other failures remain errors.

### `env(name, options?)`

Creates an environment layer. `EnvLayerOptions` exposes `case`, `coerce`,
`enabled`, `map`, `prefix`, `secret`, `separator`, and `source`.

`EnvMap` maps variable names to a path string or `EnvMapEntry`; an entry contains
`path` and optional `EnvParser`. `EnvSource` is the injectable readonly string
map used instead of `process.env`. Supplying `map` selects explicit mode;
otherwise prefix mode applies `prefix`, `separator`, and case behavior.

### `secret(name, input, options?)`

Creates an all-secret value or loader layer. `SecretLoader<Output>` may be sync
or async. `SecretLayerOptions` contains only `enabled`; sensitivity cannot be
disabled on this helper.

### `LayerDescriptor`

The provider-neutral descriptor contains `name`, `source`, and optional
`enabled` and `secret`. Its `source` implements `LayerSource<Output>`:

```ts
interface LayerSource<Output = unknown> {
  readonly kind: string;
  readonly load: (
    context: SourceContext,
  ) => Output | Promise<Output>;
}
```

`SourceContext` contains resolved `cwd`, optional `signal`, and optional
`SourceLimits`; the current source limit is `maxSourceBytes`. `SourceMetadata`,
`SourcePathReference`, and `LoadedLayer` are public structural vocabulary for
safe provider references and load results. Core `1.0` does not expose a custom
metadata registration hook: a `LayerSource.load()` return is always treated as
configuration data, not as a `LoadedLayer` envelope.

Extension rules:

- return data only; core owns normalization, precedence, merge, validation,
  provenance, redaction, and snapshot construction;
- honor `signal` when the provider supports cancellation;
- keep credentials and configuration values out of names, references, errors,
  and metadata;
- do not attach `SourceMetadata` to a custom source expecting core to consume
  it; source identity remains its descriptor name and kind;
- do not depend on deep imports, global registration, or accumulated config;
- treat the source/parser as trusted executable application code, while its
  returned value is untrusted data.

See [ADR-0003](./adr/0003-extension-boundary.md) for the stable extension
boundary.

## Merge and secret markers

`MergeStrategy` is exactly `replace | merge | append | prepend`.
`ProvenanceMode` is exactly `none | origin-only | full`. The `remove` export is
a unique operation marker accepted at the root or as an object property value;
it is not a merge strategy and cannot appear inside arrays.

`secretValue(value)` returns an opaque `SecretValue<Value>` marker. Kasane
unwraps it before normalization and records sensitivity in provenance. The
marker must not be persisted as application configuration.

`FingerprintKey` is `string | Uint8Array`. `SecretFingerprint` is a versioned,
algorithm-labelled SHA-256 or HMAC-SHA-256 string. Fingerprints are comparison
aids, not encryption or password hashes.

## `ConfigSnapshot<T>`

`ConfigSnapshot` is both the public instance type and a runtime constructor.
Applications normally receive it from `kasane()`. Constructing it directly
creates a detached, frozen value-only snapshot without source provenance.

| Member | Return | Contract |
| --- | --- | --- |
| `value` | `DeepReadonly<T>` | Raw configuration, including secrets |
| `get(path)` | `unknown` | Raw value or `undefined` |
| `has(path)` | `boolean` | Distinguishes a missing path from a present value |
| `require(path)` | `unknown` | Raw value or `KasanePathError` |
| `origin(path)` | `Origin \| undefined` | Current source when provenance exists |
| `explain(path)` | `Explanation` | Redacted found/missing explanation |
| `diff(other)` | `ConfigDiff` | Bounded, redacted, source-aware changes |
| `toJSON()` | `RedactedConfigNode` | Detached safe diagnostic tree |

`DeepReadonly` is recursive at the type level. `RedactedConfigNode` describes a
safe diagnostic tree and deliberately does not promise the raw `T` shape.

### Explanation types

`Explanation` combines `ExplanationData` with `ExplanationMethods.format()`.
The data union is `FoundExplanationData | MissingExplanationData`. Current
source identity uses `Origin` and `OriginLayer`; origin numeric IDs are only
comparable within one snapshot.

Full provenance history is the `ExplanationHistoryEntry` union of
`ExplanationValueHistoryEntry`, `ExplanationRedactedHistoryEntry`, and
`ExplanationOperationHistoryEntry`. Public history values are safe diagnostic
values; secret entries use fingerprints rather than plaintext.

### Diff types

`ConfigDiff` contains `ConfigChange[]`. `ConfigChangeType` and the
`ConfigChange` union distinguish:

- `AddedConfigChange`;
- `RemovedConfigChange`;
- `ValueChangedConfigChange`;
- `SourceChangedConfigChange`;
- `ValueAndSourceChangedConfigChange`.

Each `ConfigDiffSide` has a safe value, optional fingerprint, and `DiffSource`.
The source is `AvailableDiffSource | UnavailableDiffSource`; unavailable source
information is explicit and is never inferred.

## Validation

`ValidationAdapter` is `FunctionValidator | StandardSchemaV1`.
`FunctionValidator<Output>` receives `unknown` and returns an output or promise.
`InferValidationOutput` derives the resolved output type. Failed Standard Schema
results become sorted, safe `ConfigIssue` records; `ConfigIssuePrevious`
describes prior redacted value/origin context when available.

The `@worldhacker/kasane/standard-schema` subpath exports:

### `isStandardSchemaV1(value)`

Returns whether a value structurally exposes a Standard Schema V1 contract.

### `StandardSchemaV1<Input, Output>`

Local structural interface compatible with Standard Schema V1, including its
namespace result, issue, path, options, types, and inference helpers. Schema
libraries remain optional consumer dependencies.

## Lifecycle events

`KasaneEventCallback` receives the frozen, value-free `KasaneEvent` union.
`KasaneEventType` covers source, merge, validation, and snapshot creation.

Start records are `SourceStartEvent`, `MergeStartEvent`, and
`ValidationStartEvent`. Completed records are `SourceEndEvent`, `MergeEndEvent`,
`ValidationEndEvent`, and `SnapshotCreatedEvent`. `LayerEventIdentity` supplies
safe layer/kind identity; `CompletedEventMetrics` supplies `durationMs`, `nodes`,
and `success`. Callback failures do not alter pipeline behavior.

## Errors

All controlled failures extend `KasaneError`:

| Class | Stable code | Category |
| --- | --- | --- |
| `KasaneLayerError` | `KASANE_LAYER_ERROR` | Options, layer, or descriptor declaration |
| `KasaneSourceError` | `KASANE_SOURCE_ERROR` | Source load, parse, mapping, or abort |
| `KasaneMergeError` | `KASANE_MERGE_ERROR` | Normalization, merge, or absent root |
| `KasaneValidationError` | `KASANE_VALIDATION_ERROR` | Validator failure or unsafe output |
| `KasanePathError` | `KASANE_PATH_ERROR` | Invalid or required-missing path |
| `KasaneSecurityError` | `KASANE_SECURITY_ERROR` | Resource or security-policy violation |

`KasaneErrorJson`, `KasaneErrorDetails`, `KasaneErrorDetailsInput`,
`KasaneErrorOptions`, and `KasaneCauseSummary` describe the allowlisted public
shape. Original arbitrary causes are not public; JSON and inspection receive a
detached sanitized summary.
